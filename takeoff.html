    OPTIONAL BROWSER AI

    Suggest electrical categories

    AI matches layer and block names to electrical categories. It does not identify unnamed symbols from their appearance or infer equipment ratings.

    First use downloads a model and runtime from Hugging Face / jsDelivr. Inference runs locally; drawing contents are not uploaded.

    Review before estimating

    1. Check the scale against a known dimension.
    2. Select only the layers and symbols in scope.
    3. Set descriptions, rates, runs and allowances.
    4. Review the exclusions before transferring.

    Every quantity retains its drawing layer and block reference. A BOM groups the same measured items by description and unit; accessories are not invented.
